## Overview

Fantasy Value is a web-based resource for fantasy baseball analysis, with an emphasis on daily fantasy sports. It gives users a dedicated way to examine player value while conducting baseball research and preparing lineups.

Rather than combining this work with broad baseball information, the project concentrates on fantasy player evaluation. That focused approach supports repeated daily review and side-by-side comparison during a fantasy research routine.
